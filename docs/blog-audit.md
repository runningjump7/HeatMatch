## Post Template

When a post is published, add it here:

```
### [Post Title]
- **Date:** YYYY-MM-DD
- **Slug:** kebab-case-slug
- **Topic:** Category (e.g., Maintenance, Costs, How-To, Local)
- **Languages:** EN, ZH-CN, ZH-TW (or which ones translated)
- **Views:** (updated after 2 weeks)
- **Avg Time on Page:** XX seconds
- **Click-Through to Lead:** X%
- **Notes:** Any insights (e.g., "performed well", "needs update", "trending topic")
```

### Heat Pump Maintenance Before Winter
